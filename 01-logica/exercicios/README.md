# Exercícios de Lógica em Java

Lista inicial de exercícios para praticar lógica de programação usando Java puro.

Estes exercícios foram organizados para treinar raciocínio passo a passo, começando por operações simples e avançando para condicionais, loops e métodos.

## Como resolver

Resolva um exercício por branch e por pull request.

Sugestão de estrutura para cada solução:

```text
01-logica/exercicios/
  ex01-operacoes-basicas/
    Ex01OperacoesBasicas.java
```

No início, use classes simples, sem `package`, para facilitar a compilação e execução pelo terminal:

```bash
javac Ex01OperacoesBasicas.java
java Ex01OperacoesBasicas
```

## 01 - Fundamentos e Operadores

**1. Operações básicas**

Crie um programa que receba dois números e mostre a soma, subtração, multiplicação e divisão entre eles.

**2. Dobro e triplo**

Crie um programa que receba um número e mostre seu dobro e seu triplo.

**3. Valor absoluto**

Crie um programa que receba um número e mostre seu valor absoluto.

**4. Maior de dois números**

Crie um programa que receba dois números e mostre qual deles é o maior.

**5. Média de três números**

Crie um programa que receba três notas e calcule a média.

**6. Conversão de temperatura**

Crie um programa que receba uma temperatura em Celsius e converta para Fahrenheit.

**7. Área de um retângulo**

Crie um programa que receba base e altura e calcule a área de um retângulo.

**8. Antecessor e sucessor**

Crie um programa que receba um número inteiro e mostre seu antecessor e sucessor.

**9. Salário com desconto**

Crie um programa que receba um salário e um percentual de desconto, calculando o valor final.

**10. Minutos para horas**

Crie um programa que receba uma quantidade de minutos e mostre o equivalente em horas e minutos.

## 02 - Condicionais

**11. Positivo, negativo ou zero**

Crie um programa que receba um número e informe se ele é positivo, negativo ou zero.

**12. Par ou ímpar**

Crie um programa que receba um número inteiro e informe se ele é par ou ímpar.

**13. Aprovação por nota**

Crie um programa que receba uma nota de 0 a 10 e informe se o aluno foi aprovado ou reprovado.

**14. Classificação por idade**

Crie um programa que receba uma idade e classifique a pessoa como criança, adolescente, adulto ou idoso.

**15. Múltiplo de 3 e 5**

Crie um programa que receba um número e informe se ele é múltiplo de 3, de 5, de ambos ou de nenhum.

**16. Saudação por turno**

Crie um programa que receba um turno (`M`, `T` ou `N`) e mostre a saudação adequada.

**17. Aumento por faixa salarial**

Crie um programa que receba um salário e aplique um percentual de aumento com base em faixas salariais.

**18. Maior de três números**

Crie um programa que receba três números e mostre o maior deles.

**19. Calculadora simples**

Crie um programa que receba dois números e uma operação (`+`, `-`, `*`, `/`) e mostre o resultado.

**20. Ano bissexto**

Crie um programa que receba um ano e informe se ele é bissexto.

## 03 - Loops

**21. Contagem de 1 até N**

Crie um programa que receba um número `N` e imprima todos os números de 1 até `N`.

**22. Soma de 1 até N**

Crie um programa que receba um número `N` e calcule a soma de todos os números de 1 até `N`.

**23. Tabuada**

Crie um programa que receba um número e mostre sua tabuada de 1 a 10.

**24. Contar pares até N**

Crie um programa que receba um número `N` e conte quantos números pares existem de 1 até `N`.

**25. Contagem regressiva**

Crie um programa que receba um número `N` e imprima os números de `N` até 1.

**26. Fatorial**

Crie um programa que receba um número inteiro não negativo e calcule seu fatorial.

**27. Fibonacci**

Crie um programa que receba um número `N` e mostre os `N` primeiros termos da sequência de Fibonacci.

**28. Soma até zero**

Crie um programa que leia números repetidamente até receber `0` e, ao final, mostre a soma total.

**29. Número primo**

Crie um programa que receba um número inteiro e informe se ele é primo.

**30. Pirâmide numérica**

Crie um programa que receba um número `N` e imprima uma pirâmide numérica com `N` linhas.

## 04 - Métodos

**31. Método de soma**

Crie um método que receba dois números inteiros e retorne a soma.

**32. Método para dobro**

Crie um método que receba um número e retorne seu dobro.

**33. Método para verificar paridade**

Crie um método que receba um número inteiro e retorne se ele é par.

**34. Método para maior número**

Crie um método que receba dois números e retorne o maior.

**35. Método para média**

Crie um método que receba três notas e retorne a média.

## Checklist antes do PR

Antes de abrir o pull request, confira:

* o arquivo compila com `javac`;
* o programa executa sem erro;
* existe pelo menos um exemplo de entrada e saída;
* o exercício resolvido está na pasta correta;
* o PR altera apenas o exercício proposto.
