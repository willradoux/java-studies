# Exercícios de Frameworks Java

Estes exercícios entram depois de um pouco de POO e estruturas de dados. A ordem ideal é: JUnit, Maven, Spring Boot, JPA/Hibernate e Spring Security.

## JUnit e AssertJ

1. Teste uma classe `Calculadora`.
2. Teste uma classe `ValidadorCpf` com casos válidos e inválidos.
3. Teste saque em `ContaBancaria`.
4. Teste cadastro de produto com preço inválido.
5. Teste média de notas.
6. Teste ordenação de alunos por nome.
7. Teste busca de produto por código.
8. Teste exceção esperada.
9. Teste lista vazia.
10. Teste regra de aprovação de aluno.

## Maven

11. Criar projeto Maven simples.
12. Adicionar dependência de teste.
13. Configurar versão do Java.
14. Rodar testes pelo terminal.
15. Separar código de produção e código de teste.
16. Adicionar plugin de empacotamento.
17. Gerar `.jar`.
18. Criar perfil de desenvolvimento.
19. Ler dependências no `pom.xml`.
20. Explicar ciclo `compile`, `test` e `package`.
