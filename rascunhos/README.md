# Rascunhos

Pasta para testes soltos, ideias incompletas e arquivos que ainda não viraram exercício ou projeto organizado.

Quando um rascunho começar a fazer sentido, mova para:

* `ucsal/`, se for atividade da faculdade;
* `java-lab/`, se for prática com estrutura Java;
* `exercicios/`, se virar enunciado de treino.
