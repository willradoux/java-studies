# Java Studies

Repositório dedicado aos meus estudos e à minha evolução com Java.

O projeto começou durante minha graduação em Engenharia de Software na UCSAL, mas também reúne estudos independentes, exercícios, desafios e pequenos projetos desenvolvidos enquanto aprofundo meus conhecimentos em programação.

## Objetivo

Construir uma base sólida em programação, lógica, resolução de problemas e Java, registrando minha evolução desde os fundamentos até conteúdos mais avançados.

## Conteúdos

* Lógica de Programação
* Fundamentos de Java
* Programação Orientada a Objetos
* Estruturas de Dados
* Algoritmos
* Exercícios
* Desafios
* Projetos
* Conteúdos acadêmicos da UCSAL

## Estrutura

As pastas numeradas representam a trilha principal de estudos, organizada de forma gradual conforme minha evolução em programação e Java.

* `01-logica/`: fundamentos de lógica de programação, operadores, condicionais, loops, métodos e exercícios iniciais.
* `02-fundamentos-java/`: conceitos básicos da linguagem Java, como tipos, arrays, strings e entrada/saída.
* `03-poo/`: estudos de Programação Orientada a Objetos, incluindo classes, encapsulamento, herança, polimorfismo e interfaces.
* `04-estruturas-de-dados/`: espaço reservado para estudos futuros sobre estruturas de dados.
* `05-algoritmos/`: espaço reservado para estudos futuros sobre algoritmos.
* `desafios/`: problemas voltados ao desenvolvimento de lógica e resolução de problemas.
* `projetos/`: pequenos projetos desenvolvidos durante os estudos.
* `ucsal/`: materiais diretamente relacionados à graduação, separados entre aulas e atividades.

## UCSAL

A pasta `ucsal/` concentra apenas conteúdos diretamente ligados à faculdade.

* `ucsal/aulas/`: exemplos, anotações e códigos desenvolvidos durante as aulas.
* `ucsal/atividades/`: listas, trabalhos e exercícios solicitados pela graduação.

Quando um conteúdo estudado na UCSAL também for importante para meu aprofundamento pessoal, ele poderá ser revisitado e implementado nas pastas temáticas principais.

## Filosofia do repositório

Este repositório funciona como um registro contínuo da minha evolução em programação. Os códigos representam diferentes etapas do aprendizado e podem ser refatorados ou revisitados conforme meus conhecimentos avançarem.

O objetivo não é apenas armazenar código pronto, mas acompanhar o processo de aprendizagem com organização, clareza e crescimento gradual.

## Commits

As mensagens de commit devem ser simples e descritivas.

Exemplos:

```text
study: practice conditional statements
study: add exercises about Java arrays
study: add notes about object-oriented programming
feat: add fibonacci challenge
refactor: simplify prime number validation
fix: correct loop condition
docs: update data structures notes
```
