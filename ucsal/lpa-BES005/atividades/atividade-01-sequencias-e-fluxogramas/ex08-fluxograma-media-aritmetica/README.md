# Exercício 08 - Fluxograma: Média Aritmética

## Enunciado

Refaça o Exercício 1 da aula anterior para representar, por meio de fluxograma, o algoritmo que calcula e mostra a média final do semestre de um aluno, considerando a média aritmética das 3 notas das avaliações realizadas.

## O que fazer

* Criar o fluxograma na pasta `fluxograma/`.
* Se quiser testar o raciocínio em Java, criar ou reaproveitar um código simples na pasta `codigo/`.

## Entradas

* primeira nota;
* segunda nota;
* terceira nota.

## Saída

* média final do aluno.

## Arquivos sugeridos

```text
codigo/MediaAritmetica.java
fluxograma/fluxograma-media-aritmetica.png
```
