# Exercício 06 - Fluxograma: Divisão de Dois Números

## Enunciado

Faça o fluxograma de um algoritmo que calcule e mostre na tela a divisão do primeiro número pelo segundo.

## O que fazer

* Criar o fluxograma na pasta `fluxograma/`.
* Se quiser testar o raciocínio em Java, criar um código simples na pasta `codigo/`.

## Entradas

* primeiro número;
* segundo número.

## Saída

* resultado da divisão do primeiro número pelo segundo.

## Atenção

Pense no que acontece se o segundo número for zero. Se a aula ainda não pediu validação, registre essa dúvida para discutir depois.
