## Checklist de entrega

Antes de entregar, confira:

* cada exercício está na pasta correta;
* os códigos Java compilam sem erro;
* os fluxogramas representam entrada, processamento e saída;
* nomes de arquivos estão claros;
* não há arquivos `.class` na entrega;
* o que for entregue está organizado e fácil de localizar.
