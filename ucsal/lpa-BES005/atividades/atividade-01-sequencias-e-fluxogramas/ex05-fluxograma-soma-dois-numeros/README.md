# Exercício 05 - Fluxograma: Soma de Dois Números

## Enunciado

Faça o fluxograma de um algoritmo que calcule e mostre na tela a soma de 2 números.

## O que fazer

* Criar o fluxograma na pasta `fluxograma/`.
* Se quiser testar o raciocínio em Java, criar um código simples na pasta `codigo/`.

## Entradas

* primeiro número;
* segundo número.

## Saída

* soma dos dois números.

## Arquivos sugeridos

```text
codigo/SomaDoisNumeros.java
fluxograma/fluxograma-soma-dois-numeros.png
```
