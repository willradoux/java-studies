# Exercício 02 - Média Ponderada com Pesos Fixos

## Enunciado

Refaça o algoritmo anterior, considerando que a média final é calculada através da média ponderada das 3 notas das avaliações realizadas.

Pesos:

* 1ª nota: peso 2;
* 2ª nota: peso 3;
* 3ª nota: peso 5.

## O que fazer

* Criar o algoritmo em Java na pasta `codigo/`.
* Se quiser treinar também o desenho, criar o fluxograma na pasta `fluxograma/`.

## Entradas

* primeira nota;
* segunda nota;
* terceira nota.

## Saída

* média ponderada final.
