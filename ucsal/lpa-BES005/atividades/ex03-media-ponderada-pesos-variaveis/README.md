# Exercício 03 - Média Ponderada com Pesos Variáveis

## Enunciado

Refaça o algoritmo anterior, considerando que a média final é calculada através da média ponderada das 3 notas das avaliações realizadas, sabendo que os pesos são definidos de acordo com a disciplina e o professor.

## O que fazer

* Criar o algoritmo em Java na pasta `codigo/`.
* Permitir que os pesos sejam informados.
* Se quiser treinar também o desenho, criar o fluxograma na pasta `fluxograma/`.

## Entradas

* primeira nota;
* segunda nota;
* terceira nota;
* peso da primeira nota;
* peso da segunda nota;
* peso da terceira nota.

## Saída

* média ponderada final.

## Arquivos sugeridos

```text
codigo/MediaPonderadaPesosVariaveis.java
fluxograma/fluxograma-media-ponderada-pesos-variaveis.png
```
