# Exercício 07 - Fluxograma: Estoque Médio

## Enunciado

Faça o fluxograma de um algoritmo para calcular o estoque médio de uma peça.

Fórmula:

```text
ESTOQUE MÉDIO = (QUANTIDADE MÍNIMA + QUANTIDADE MÁXIMA) / 2
```

## O que fazer

* Criar o fluxograma na pasta `fluxograma/`.
* Se quiser testar o raciocínio em Java, criar um código simples na pasta `codigo/`.

## Entradas

* quantidade mínima;
* quantidade máxima.

## Saída

* estoque médio.

```text
codigo/EstoqueMedio.java
fluxograma/fluxograma-estoque-medio.png
```
