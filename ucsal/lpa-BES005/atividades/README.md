## Organização sugerida

Cada atividade deve ficar em uma pasta própria, com os enunciados, códigos e fluxogramas separados.

```text
atividade-XX-nome-da-atividade/
  README.md
  ex01-nome/
    README.md
    codigo/
    fluxograma/
```

Use a pasta `codigo/` para arquivos `.java` e a pasta `fluxograma/` para imagens, PDFs ou arquivos da ferramenta usada para desenhar o fluxograma.
