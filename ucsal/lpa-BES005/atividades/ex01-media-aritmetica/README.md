# Exercício 01 - Média Aritmética

## Enunciado

Sabendo que a média final do semestre é calculada através da média aritmética das 3 notas das avaliações realizadas, faça um algoritmo que calcule e mostre a média de um determinado aluno.

## O que fazer

* Criar o algoritmo em Java na pasta `codigo/`.
* Se quiser treinar também o desenho, criar o fluxograma na pasta `fluxograma/`.

## Entradas

* primeira nota;
* segunda nota;
* terceira nota.

## Saída

* média final do aluno.

## Arquivos sugeridos

```text
codigo/MediaAritmetica.java
fluxograma/fluxograma-media-aritmetica.png
```
