# Exercício 09 - Fluxograma: Média Ponderada com Pesos Fixos

## Enunciado

Refaça o Exercício 2 da aula anterior para representar, por meio de fluxograma, o algoritmo que calcula e mostra a média final do semestre de um aluno, considerando a média ponderada das 3 notas das avaliações realizadas.

Pesos:

* 1ª nota: peso 2;
* 2ª nota: peso 3;
* 3ª nota: peso 5.

## O que fazer

* Criar o fluxograma na pasta `fluxograma/`.
* Se quiser testar o raciocínio em Java, criar ou reaproveitar um código simples na pasta `codigo/`.

## Entradas

* primeira nota;
* segunda nota;
* terceira nota.

## Saída

* média ponderada final.

```text
codigo/MediaPonderadaPesosFixos.java
fluxograma/fluxograma-media-ponderada-pesos-fixos.png
```
