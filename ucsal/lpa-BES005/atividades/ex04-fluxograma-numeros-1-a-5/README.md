# Exercício 04 - Fluxograma: Números de 1 a 5

## Enunciado

Faça o fluxograma de um algoritmo que mostre na tela os números de 1 a 5.

## O que fazer

* Criar o fluxograma na pasta `fluxograma/`.
* Se quiser testar o raciocínio em Java, criar um código simples na pasta `codigo/`.

## Saída esperada

* números de 1 a 5 exibidos na tela.

## Arquivos sugeridos

```text
codigo/NumerosUmACinco.java
fluxograma/fluxograma-numeros-1-a-5.png
```
