# Dashboard de Progresso

Use este arquivo para acompanhar evolução de forma realista.

Não aumente uma nota porque "parece que entendeu". A nota sobe quando existe evidência prática.

## Escala

| Nível | Significado |
| --- | --- |
| 0 | Nunca estudado |
| 1 | Reconheço o assunto |
| 2 | Entendo com ajuda |
| 3 | Consigo aplicar em exercícios simples |
| 4 | Consigo resolver sozinho |
| 5 | Consigo explicar e resolver variações |

## Error Log

Registre erros relevantes neste formato:

```text
Data:
Exercício:
Categoria:
O que eu esperava:
O que aconteceu:
Causa provável:
Como corrigir:
Como evitar:
```

## Categorias de erro

| Categoria | Exemplo |
| --- | --- |
| Sintaxe | esquecer `;`, chaves ou assinatura do `main` |
| Tipos | usar `int` quando precisa de `double` |
| Condição | usar `>` quando deveria ser `>=` |
| Loop | condição de parada errada |
| Off-by-one | começar ou terminar uma posição antes/depois |
| Interpretação | resolver outro problema que não era o enunciado |
| Array | acessar índice fora do limite |
| String | comparar com `==` em vez de `.equals` |
| Estrutura | usar lista quando um conjunto seria melhor |
| Complexidade | criar loop duplo desnecessário |
| Debug | não conseguir localizar onde o valor muda |

## Revisão semanal

Todo sábado, responda:

1. Quais exercícios resolvi?
2. Quais eu não consegui resolver?
3. Onde eu travei: interpretação, algoritmo, Java ou debug?
4. Qual erro apareceu mais de uma vez?
5. O que preciso revisar na próxima semana?
6. Usei IA cedo demais?
7. Consigo explicar uma solução em voz alta?

## Evidência de domínio

Marque um assunto como dominado somente se você conseguir:

* explicar sem ler;
* implementar de novo em outro dia;
* resolver uma variação;
* identificar edge cases;
* estimar complexidade;
* defender sua escolha em uma entrevista.
