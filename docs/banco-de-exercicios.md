Depois de resolver, responda:

1. Qual era o problema?
2. Qual foi sua ideia inicial?
3. Por que essa solução funciona?
4. Qual estrutura de dados você usou?
5. Por que escolheu essa estrutura?
6. Qual a complexidade?
7. Qual o principal edge case?
8. O que mudaria com 1 milhão de elementos?
9. Como você testaria?
10. Existe uma solução mais simples?
11. Existe uma solução mais eficiente?
12. O que você faria diferente em uma API real?
