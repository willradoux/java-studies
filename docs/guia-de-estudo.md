# Guia de Estudo

Este guia organiza a rotina do repositório. A ideia é estudar Java no geral, mas sem pular etapas importantes.

## Regra principal

Para cada tema, faça nesta ordem:

1. leia o enunciado;
2. escreva a ideia em português;
3. faça o código;
4. rode com pelo menos 3 entradas diferentes;
5. anote o que errou;
6. refatore nomes, repetição e validações;
7. faça um commit pequeno.

## Rotina sugerida

### Segunda a sexta

* 30 min: revisar teoria ou README da trilha.
* 60 min: resolver exercícios.
* 15 min: registrar erros e aprendizados.

### Sábado

* refazer exercícios que deram errado;
* subir commits;
* escolher um mini projeto.

### Domingo

* revisar o que foi estudado;
* organizar pendências;
* preparar os exercícios da semana.

## Ordem dos temas

1. lógica e entrada/saída;
2. métodos;
3. arrays e listas;
4. POO;
5. estruturas de dados;
6. testes automatizados;
7. Maven;
8. Spring Boot;
9. banco de dados com JPA/Hibernate;
10. projetos integrados.

## Como saber se aprendeu

Você aprendeu um tema quando consegue:

* explicar com suas palavras;
* resolver sem copiar;
* criar outro exercício parecido;
* refatorar o próprio código;
* encontrar erro no código antigo.
