# Exercícios Diários

Plano de exercícios para praticar todos os dias durante 8 semanas.

Não existe limite rígido de exercícios. Cada dia tem uma lista principal. Se terminar cedo, continue pelo banco extra em [Banco de Exercícios](banco-de-exercicios.md).

Regra importante: não consulte solução pronta antes de tentar.

## Como usar

Para cada exercício:

1. escreva o enunciado com suas palavras;
2. defina entrada e saída;
3. crie exemplos;
4. escreva pseudocódigo;
5. implemente em Java;
6. teste;
7. registre erros.
