# Trilha de Estudos

Esta trilha organiza o estudo de Java, lógica, estruturas de dados, algoritmos e fundamentos técnicos para a preparação do iFuture 2027 e para a base da graduação.

O objetivo não é parecer avançado. O objetivo é construir domínio real: interpretar problemas, pensar em soluções, implementar em Java, testar, depurar e explicar o raciocínio.

## Prioridade atual

Até as etapas técnicas do iFuture, a prioridade deve ser:

```text
70% Java + lógica + algoritmos + estruturas de dados
20% entrevista técnica + fundamentos de backend
10% frontend/manutenção
```

Evite abrir novas frentes como Spring Boot, AWS, Kafka, Kubernetes ou projetos grandes de frontend antes de consolidar fundamentos.

## Fase 1 - Java fundamental

Foco:

* estrutura de um programa Java;
* `main`;
* variáveis;
* tipos primitivos;
* operadores;
* entrada e saída;
* condicionais;
* loops;
* métodos;
* arrays;
* strings.

Meta:

Conseguir escrever pequenos programas sozinho, compilar, executar e corrigir erros simples.

Pastas relacionadas:

```text
01-logica/
02-fundamentos-java/
```

## Fase 2 - Lógica de programação

Foco:

* interpretação de enunciados;
* soma;
* média;
* máximo e mínimo;
* contagem;
* validação;
* busca;
* repetição;
* decomposição em passos.

Meta:

Transformar problemas simples em algoritmos antes de escrever código.

## Fase 3 - Arrays e strings

Foco:

* percorrer arrays;
* acessar índices;
* evitar erros de limite;
* buscar valores;
* contar ocorrências;
* inverter dados;
* manipular caracteres;
* comparar strings;
* normalizar texto.

Meta:

Resolver problemas comuns de assessment envolvendo listas simples e texto.

## Fase 4 - Collections e estruturas de dados

Foco:

* `ArrayList`;
* `HashMap`;
* `HashSet`;
* `Stack`;
* `Queue`;
* `Deque`;
* `PriorityQueue`.

Meta:

Entender qual problema cada estrutura resolve e quando ela é mais adequada.

Perguntas obrigatórias:

* Por que usar array aqui?
* Por que usar `ArrayList` aqui?
* Por que `HashMap` melhora essa solução?
* O que `HashSet` evita?
* Onde aparece comportamento de pilha?
* Onde aparece comportamento de fila?

## Fase 5 - Algoritmos e Big O

Foco:

* busca linear;
* busca binária;
* ordenação;
* two pointers;
* sliding window básico;
* prefix sum;
* recursão básica;
* análise de complexidade.

Meta:

Começar a responder:

* Quantas vezes percorro os dados?
* Existe loop dentro de loop?
* Existe busca repetida?
* Posso usar hash para reduzir custo?
* Minha solução é `O(n)`, `O(n log n)` ou `O(n²)`?

## Plano inicial de 8 semanas

| Semana | Foco principal | Meta prática |
| --- | --- | --- |
| 1 | Java básico, tipos, operadores e primeiros condicionais | Escrever programas simples sem copiar |
| 2 | Condicionais, loops e métodos | Resolver problemas com repetição e funções |
| 3 | Arrays | Percorrer, buscar, contar e comparar dados |
| 4 | Strings | Manipular texto e caracteres |
| 5 | `ArrayList` e revisão de arrays | Escolher entre array e lista dinâmica |
| 6 | `HashMap` e `HashSet` | Resolver frequência, duplicados e busca eficiente |
| 7 | Stack, Queue e Big O | Entender comportamento e custo |
| 8 | Simulados e revisão | Resolver problemas mistos sob tempo |

## Critério para avançar

Não avance só porque uma semana acabou.

Avance quando conseguir:

* explicar o conceito com suas palavras;
* implementar sem copiar;
* resolver uma variação;
* testar casos simples e extremos;
* identificar erros;
* explicar a complexidade em nível básico.
