# Trilha 03 - Frameworks Java

Objetivo: sair do Java puro e começar a construir aplicações com ferramentas usadas em projetos reais.

## Antes dos frameworks

Domine primeiro:

* classes e objetos;
* listas e mapas;
* exceções;
* interfaces;
* testes básicos;
* HTTP em nível conceitual.

## Ordem sugerida

1. **JUnit + AssertJ**: testar regras pequenas.
2. **Maven**: organizar dependências e ciclo de build.
3. **Spring Boot**: criar API REST.
4. **Bean Validation**: validar entrada de dados.
5. **JPA/Hibernate**: persistir dados em banco.
6. **Spring Data JPA**: criar repositórios.
7. **Spring Security**: autenticação e autorização.
8. **Docker**: rodar banco e aplicação de forma previsível.

## Primeiros projetos

* API de tarefas;
* API de alunos e notas;
* sistema simples de biblioteca;
* controle financeiro pessoal;
* catálogo de produtos.

Os exercícios estão em [frameworks Java](../exercicios/frameworks-java.md).
